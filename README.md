# 📊 Unemployment Analysis with Python

## 📌 Overview
This project analyzes unemployment trends in India using Python and real-world datasets. It explores regional differences, monthly patterns, rural vs. urban unemployment, and the impact of COVID-19 on unemployment rates.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib

## ✨ Features
- Data cleaning and preprocessing
- Monthly unemployment trend analysis
- Pre-COVID vs. COVID-period comparison
- Region-wise unemployment analysis
- Rural vs. urban comparison
- Labour force participation analysis
- Automated charts and CSV summaries

## 📂 Project Structure
```text
Unemployment-Analysis/
├── unemployment analysis.py
├── Unemployment in India.csv
├── Unemployment_Rate_upto_11_2020.csv
└── output/
```

## ⚙️ Installation and Usage

1. Install the required libraries:
   ```bash
   pip install pandas matplotlib
   ```

2. Place both CSV datasets in the same folder as the Python script.

3. Run the project:
   ```bash
   python "unemployment analysis.py"
   ```

4. Find the generated charts and summary CSV files in the `output/` folder.
